# My First Portfolio

[Live Demo](https://sanjeevveerapandian.github.io/Portfolio/)


This is my first portfolio website, designed to showcase my skills, projects, and experiences. Built with React.js and Tailwind CSS, the portfolio features a modern and responsive design with a light/dark mode toggle for enhanced user experience.

🛠️ Features
Responsive Design: Seamlessly adapts to different screen sizes and devices.
Light/Dark Mode: Toggle between light and dark themes for a personalized experience.
Clean UI: Minimalist and professional layout for easy navigation.
Interactive Components: Smooth transitions and animations to engage users.
🖥️ Tech Stack
React.js: Component-based framework for building a dynamic UI.
Tailwind CSS: Utility-first CSS framework for rapid styling.
